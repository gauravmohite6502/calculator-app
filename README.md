# Calculator App

A simple and interactive calculator application built using Node.js and Express.js. This project demonstrates basic backend development, routing, and server-side rendering.

## 🚀 Features

* Perform basic arithmetic operations
* Addition
* Subtraction
* Multiplication
* Division
* User-friendly interface
* Node.js backend
* Express.js routing

## 🛠️ Technologies Used

* **Node.js**
* **Express.js**
* **HTML**
* **CSS**
* **JavaScript**

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/gauravmohite6502/calculator-app.git
```

### 2. Navigate to the project directory

```bash
cd calculator-app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the application

```bash
npm start
```

## 🌐 Run the Application

Open your browser and visit:

```text
http://localhost:8800
```
